# 引导式开场（Guided Onboarding）

本文件规定 b2b-facebook-ads-manager 的引导方式：何时引导、每个模式的提问顺序、缺什么怎么补、如何收尾。

## 何时引导

- 首次使用本技能。
- 请求模糊：如“帮我看看广告”“用这个技能”“你看着办”。
- 缺少必要信息：没有 token、账户或明确任务。

请求已经明确（例如“出近 30 天只读报告”）时直接进入对应模式，不重复开场问题。

## 开场

1. 一句话说明能力：本技能可以出只读报告、研究受众、诊断优化、构建 B2B 线索广告。
2. 只问一个问题：“这次你想做哪件事？”
   - 账户表现报告（只读）
   - 受众 / 兴趣 / 覆盖研究（只读）
   - 诊断与优化建议（改动需确认）
   - B2B 广告构建（文案 / 素材 / 表单 / 建广告）
3. 按选择进入对应模式并检查前置条件。

## 前置条件

| 项目 | 引导方式 |
|---|---|
| `FB_ACCESS_TOKEN` | 只报告“已设置 / 未设置”；未设置时请用户粘贴，仅当前进程临时使用，用完即删，不打印、不落盘 |
| 广告账户 | 优先从用户提供的 Ads Manager 链接或账户 ID 提取；都没有时用 token 调 `me/adaccounts` 列出可访问账户让用户选 |
| 代理 | 仅当直连失败时才询问是否设置 `FB_PROXY`，不主动要求 |

## 各模式提问顺序

### 报告模式

1. 确认账户（ID 或 Ads Manager 链接）。
2. 确认窗口：默认近 7 / 30 天、截至昨天、仅 ACTIVE；用户无要求时直接说明“使用默认口径”，不重复询问。
3. 运行主脚本生成中文 Markdown 报告，给出文件链接。
4. 收尾：总结 2-3 个关键发现，提供下一步选项（看非活跃 campaign、转 PDF、对单个 campaign 深入诊断）。

### 受众研究模式

按顺序提问，拿到一个再问下一个：

1. 目标国家 / 地区（多选，映射 ISO 代码）。
2. 产品或行业（自由文本，如“包材定制 / 包装袋”）。
3. B2B、B2C 或两者都要。

未知行业时，请用户给出 3-10 个代表词（品类词、品牌、使用场景），不用空泛猜测。

收尾：给出去重排序清单 → 请用户挑选受众 → 估算国家覆盖 → 给 `targeting_spec` 示例；最后问“要不要把选中的受众做成 PAUSED 广告组”。

### 管理模式

1. 先只读诊断：拉取结构和花费成效，输出“分析结论”。
2. 把所有建议改动单独列为“需确认后执行”，每条写明对象、动作、预期影响。
3. 用户逐条确认后才执行；执行后重读并报告对象 ID、名称、`configured_status`、`effective_status`。
4. 收尾：给出观察建议（如运行 2-3 天再决定是否关停）。

### B2B 广告构建模式

按 [b2b-ad-builder.md](b2b-ad-builder.md) 的事实简报顺序收集，每次只问缺失且必要的信息：

1. 产品名称、产品页、企业身份和品牌拼写。
2. 目标采购商、行业、应用和地区。
3. 可核实参数、兼容性、差异点。
4. 转化目的：Instant Form、WhatsApp、Messenger、网站询盘或报价请求。
5. 采购条件（MOQ、样品、OEM/ODM、认证、交期）——只在用户明确提供后使用。
6. 语气与 Emoji 密度（B2B 默认 0-2 个、少量）。

资料不足时：先按已有事实生成安全版本，另列建议补充项；不用占位符污染可投放文案。

收尾：输出 5 组英文文案（附中文翻译）→ 需要素材时按 9:16 / 1:1 / 1.91:1 制作 → 需要落地时列出拟创建对象等待确认。

## 收尾通用规则

- 每完成一步用一句话同步：“已确认：…；还需要：…”。
- 结束时分成两类：已完成结果（文件 / 文案 / 结论）和待确认动作（任何写操作）。
- 首次使用结束时，可询问是否记住常用配置（默认账户、默认国家等），但绝不把 token 写进配置或记忆。
